More context:
Introduction to EXO EXO, developed by Alex Krentsel and his colleagues at UC Berkeley, is an agent that can safely edit all aspects of itself at runtime. The project aims to optimize the architecture of AI systems to make them more efficient and secure. Architecture Decomposition: Executor, XRS (Harness), Sandbox The EXO architecture decomposes an agent into three distinct layers: 1. Executor: Contains policy decisions on how context is assembled. 2. XRS (Harness): Holds state and manages the protected layer of the agent. 3. Sandbox: The environment where actions are executed. This separation allows for isolated execution environments, protected state, and a fully stateless layer that can evolve safely.
