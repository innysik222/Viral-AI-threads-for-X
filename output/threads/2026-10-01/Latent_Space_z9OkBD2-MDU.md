### 🧠 Deep Dive
#### Superhuman Computer Use Agents
Ari Weinstein, leading the product and engineering team for computer use agents at OpenAI, highlighted that these agents are now outpacing human experts in software tasks. This development marks a significant milestone in the evolution of AI, suggesting that in the near future, AI could become superhuman in its performance. Weinstein stated, "I think that the next frontier is to have computer use be literally superhuman in its performance where it actually is as fast or faster at using software than like expert computer users like us." This advancement could lead to the creation of products that provide real-time experiences, saving users time and increasing productivity.

#### GPD 6.1 Soul Model
The introduction of GPD 6.1 Soul has been a game-changer, with its cost being reduced to a fifth of Astra's, making advanced AI more accessible to a wider audience. Weinstein shared, "GPD 6.1 Soul is a fifth of the cost as Astra and a seventh of the cost if you're looking at computer use specifically, which is really amazing." This cost reduction is a significant step towards democratizing access to advanced AI technologies.

#### New API Features
The new API features, including async tool calling and mid-turn steering, are designed to make app development more efficient. Nikunj Handa, leading the product for the API team, explained, "What you see with like a lot of the things that you're seeing in like codecs and dots and everything is that tool calls take so long that you don't have to like pause the model's execution while uh the tool is running. So you could just like kick off a tool call, keep running, keep reasoning and then check back in." These features are expected to significantly improve developer workflows, allowing for more fluid and efficient coding processes.

#### Persistent Dots
Dots, the personal assistant product, now offer persistent personal computers in the cloud. This means that users can have their own Linux virtual computer in the cloud, allowing them to run full desktop applications and use a web browser. According to Weinstein, "Each dot has access to its own Linux virtual computer in the cloud, which is different from our other products. You know, traditionally we've have access to a browser in the cloud or it has access to your own computer, but now you get your own entire Linux computer in the cloud and so it can run full desktop applications." This capability opens up new possibilities for automation and task delegation.

#### Decision API
The Decision API offers fast, reliable, and structured output, making it a powerful tool for developers handling classification tasks. Handa noted, "The main use cases we've seen is like really fast classification. All the computer use demos have been amazing and really cool." This API could significantly enhance the speed and efficiency of classification tasks, potentially changing how developers approach these tasks.
