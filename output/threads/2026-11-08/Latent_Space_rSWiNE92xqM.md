# Transforming GitHub: Jay Parikh on AI-Driven Development

**TL;DR:** Jay Parikh, EVP of CoreAI at Microsoft, discusses GitHub's evolution with AI, reaching 225 million developers, and future plans.

### 🔑 Key Insights
* **Massive Growth:** GitHub now has 225 million developers, adding one new developer every second, with 40% of pull requests created by agents.
* **Agent Collaboration:** The rise of coding agents is changing how humans and machines collaborate, with agent-created PRs growing six times in six months.
* **Security and Scalability:** GitHub is focusing on advanced security features and cost management tools, ensuring the platform can handle massive growth.

### 🧠 Deep Dive
#### Massive Developer Growth
According to Jay Parikh, GitHub has seen explosive growth, adding 31.5 million developers in the last year alone. This staggering growth highlights the platform's importance in the developer community. Parikh notes, "Adding one developer every second is enormous and mindboggling."

#### Agent Collaboration
The integration of coding agents into the development process is revolutionizing collaboration. Parikh explains, "Now with coding agents, you don't have to be a skilled software engineer to use GitHub. You can share ideas, get feedback, and build things together." This shift is enabling more people to participate in the development process.

#### Security and Scalability
GitHub is also prioritizing advanced security features, using AI-powered scanning technologies to detect and prevent secret pushes. Parikh states, "We have a lot of work going on here. We still have lots of work to do. A few things here. One from a product or feature perspective. We talked about a number of things that we're doing around like now we have code review max and that should, you know, even help find higher severity, more obscure bugs in the code, etc."

#### Future Plans
Looking ahead, Parikh predicts significant improvements in every layer of the stack. He envisions a future where the platform will continue to evolve, with more agents and enhanced cost management tools. Parikh notes, "We'll continue down this path that we talked about today which is how do we keep evolving every layer of the stack."

### 💬 Notable Quotes
> "You don't have to be a skilled software engineer to use GitHub now. Coding agents can help build things together." - Jay Parikh, EVP of CoreAI, Microsoft.

### 🏁 Conclusion
The future of development is being rewritten with GitHub's AI-driven approach. As the platform continues to grow and evolve, it will play an even more crucial role in the development community. Stay informed and prepare for the changes ahead.
